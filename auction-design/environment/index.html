Environment

A monopoly seller has an object for which she has no value. There are \(n\geq 1\) risk-neutral potential buyers. The buyers have independent, private values \(V_i\sim F_i\), \(i=1,\ldots,n\). We assume that each \(F_i\) has a continuous, strictly positive density \(f_i\) on its support \([\underline{v}_i,\overline{v}_i]\).

By the Revelation Principle, to implement any desired outcome rule, we can consider only direct selling mechanisms which consist of an allocation rule \(q:T\to[0,1]^n\) and a payment rule \(p:T\to\mathbb{R}^n\), where \(T=\prod_{i=1}^n[\underline{v}_i,\overline{v}_i]\). As functions of the reported values, for each buyer, the allocation rule specifies the probability the object is sold to him, and the payment rule specifies the expected payment from him. Writing \(q=(q_1,\ldots,q_n)\), since there is only one object to be sold, we require that for all \(v\in T\), \(\sum_{i=1}^n q_i(v)\leq 1.\)

Define the following properties of a mechanism:

  1. (Bayesian, respectively, Dominant Strategy) Incentive Compatibility (IC): Truthful reporting by all buyers is a Bayesian Nash (respectively, Dominant Strategy) equilibrium.
  2. (Interim) Individual Rationality (IR): In truthful equilibrium, after observing their values, all buyers have a weakly positive expected payoff.

Write \(v_{-i}=(v_1,\ldots,v_{i-1},v_{i+1},\ldots,v_n)\), \(T_{-i}=\prod_{j\ne i}[\underline{v}_j,\overline{v}_j]\), and \(f_{-i}(v_{-i})=\prod_{j\ne i}f_j(v_j)\).

Denote for buyer \(i\), \(i=1,\ldots,n\), with value \(v_i\) who reports \(v_i'\), given the other buyers report truthfully:

  • \(\displaystyle Q_i(v_i')=\int_{T_{-i}} q_i(v_i',v_{-i})\,f_{-i}(v_{-i})\,dv_{-i}\), his interim probability of receiving the object;
  • \(\displaystyle P_i(v_i')=\int_{T_{-i}} p_i(v_i',v_{-i})\,f_{-i}(v_{-i})\,dv_{-i}\), his interim expected payment to the mechanism;
  • \(\displaystyle U_i(v_i,v_i')=v_i\,Q_i(v_i')-P_i(v_i')\), his interim expected payoff;
  • \(\displaystyle \phi_i(v_i)=v_i-\frac{1-F_i(v_i)}{f_i(v_i)}\), his virtual value.

For compactness, we'll write \(U_i(v_i,v_i)\) as \(U_i(v_i)\).

We call an allocation rule \(q\) BIC (respectively, DSIC) implementable if and only if there exists a payment rule \(p\) such that the mechanism \((q,p)\) is BIC (respectively, DSIC).

We call this environment regular if and only if \(\phi_i\) is weakly increasing, \(i=1,\ldots,n\).
