Optimal Auctions

In the single-item auction environment, Myerson (1981) gives the following result:

Theorem (): When the environment is regular, a BIC, IR, revenue-maximizing mechanism is a second-price auction in virtual values with reserve values \(r_i=\inf\{t\in T_i\mid\phi_i(t)\geq 0\}\), \(i=1,\ldots,n\).

For each buyer \(i\) and fixed reports \(v_{-i}\), denote

\[ x_i(v_{-i})=\inf\{t\in T_i\mid\phi_i(t)\geq\max\{0,\phi_j(v_j)\mid j\ne i\}\}. \]

Then, equivalently, \((q^*,p^*)\)1 is an optimal mechanism where for \(i=1,\ldots,n\),

\[ q_i^*(v)=\begin{cases} 1 & \text{if } \phi_i(v_i)\geq 0\\ 0 & \text{otherwise} \end{cases}, \qquad p_i^*(v)=q_i^*(v)x_i(v_{-i}). \]

Incentive compatibility and individual rationality

We can write the BIC and interim IR conditions as the following inequalities for every buyer \(i=1,\ldots,n\) and value \(v_i\in[\underline{v}_i,\overline{v}_i]\):

  • BIC: \(\displaystyle U_i(v_i)\geq U_i(v_i,v_i')\), for all \(v_i'\in[\underline{v}_i,\overline{v}_i]\);
  • IR: \(\displaystyle U_i(v_i)\geq 0\).

Applying Myerson's Lemma to this environment gives that \((q,p)\) is BIC if and only if, for every buyer \(i\), \(Q_i\) is weakly increasing and the interim expected payments satisfy for all \(v_i\in[\underline{v}_i,\overline{v}_i]\)

\[ P_i(v_i)=v_iQ_i(v_i)-U_i(\underline{v}_i)-\int_{\underline{v}_i}^{v_i} Q_i(t)\,dt. \]

These interim payments set truthful interim expected utilities for all \(v_i\in[\underline{v}_i,\overline{v}_i]\) as

\[ U_i(v_i)=U_i(\underline{v}_i)+\int_{\underline{v}_i}^{v_i} Q_i(t)\,dt. \]

Notice in the interim payments above we are free to choose \(U_i(\underline{v}_i)\) without affecting BIC implementability. As long as we choose \(U_i(\underline{v}_i)\geq 0\) for every buyer \(i\), the mechanism will also be interim IR, since \(Q_i(v_i)\geq 0\).

Expected revenue

Now that we have interim expected payments, we can calculate ex-ante expected payments from each buyer directly, the sum of which is expected revenue. Write \(V=(V_1,\ldots,V_n)\) for the vector of buyers' random values. From buyer \(i\), we can expect to receive

\(\displaystyle \mathbb{E}\!\left[p_i(V)\right]\) \(\displaystyle =\) \(\displaystyle \mathbb{E}\!\left[P_i(V_i)\right], \text{ by the law of iterated expectations}\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} P_i(v_i)\,f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} \left(v_iQ_i(v_i)-U_i(\underline{v}_i)-\int_{\underline{v}_i}^{v_i} Q_i(t)\,dt\right) f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} \left(v_iQ_i(v_i)-U_i(\underline{v}_i)\right) f_i(v_i)\,dv_i - \int_{\underline{v}_i}^{\overline{v}_i}\int_{\underline{v}_i}^{v_i} Q_i(t)\,dt\,f_i(v_i)\,dv_i.\)

To compute this, we first simplify the final term.

\(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i}\int_{\underline{v}_i}^{v_i} Q_i(t)\,dt\,f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i}\int_{\underline{v}_i}^{v_i} Q_i(t)\,f_i(v_i)\,dt\,dv_i\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i}\int_{t}^{\overline{v}_i} Q_i(t)\,f_i(v_i)\,dv_i\,dt \text{, by Fubini's Theorem}\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} Q_i(t)\int_{t}^{\overline{v}_i} f_i(v_i)\,dv_i\,dt\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} Q_i(t)\left(\int_{\underline{v}_i}^{\overline{v}_i} f_i(v_i)\,dv_i-\int_{\underline{v}_i}^{t} f_i(v_i)\,dv_i\right)dt\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} Q_i(t)\left(1-F_i(t)\right)dt\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} Q_i(v_i)\left(1-F_i(v_i)\right)dv_i.\)

Substituting back into the earlier expected payment calculation,

\(\displaystyle \mathbb{E}\!\left[p_i(V)\right]\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} v_iQ_i(v_i)\,f_i(v_i)\,dv_i - \int_{\underline{v}_i}^{\overline{v}_i} U_i(\underline{v}_i)\,f_i(v_i)\,dv_i - \int_{\underline{v}_i}^{\overline{v}_i} Q_i(v_i)\left(1-F_i(v_i)\right)dv_i\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} v_iQ_i(v_i)f_i(v_i)\,dv_i -U_i(\underline{v}_i) - \int_{\underline{v}_i}^{\overline{v}_i} Q_i(v_i)\frac{1-F_i(v_i)}{f_i(v_i)}f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle -U_i(\underline{v}_i) + \int_{\underline{v}_i}^{\overline{v}_i} Q_i(v_i)\left(v_i-\frac{1-F_i(v_i)}{f_i(v_i)}\right)f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle -U_i(\underline{v}_i) + \int_{\underline{v}_i}^{\overline{v}_i} Q_i(v_i)\,\phi_i(v_i)\,f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle -U_i(\underline{v}_i) + \mathbb{E}\!\left[Q_i(V_i)\,\phi_i(V_i)\right],\)

recalling the earlier definition of buyer \(i\)'s virtual value \(\phi_i(v_i)\).

For the step involving Fubini's Theorem, note that we assume \(f_i\) is continuous on the compact interval \([\underline{v}_i,\overline{v}_i]\), and is therefore bounded. Similarly \(Q_i\) is, by definition, bounded. Thus, the integrand is absolutely integrable, permitting the change in integration order.

Let's rewrite the expected value term to be more convenient for later calculations.

\(\displaystyle \mathbb{E}\!\left[Q_i(V_i)\,\phi_i(V_i)\right]\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} Q_i(v_i)\,\phi_i(v_i)\,f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i} \int_{T_{-i}} q_i(v_i,v_{-i})\,f_{-i}(v_{-i})\,dv_{-i}\,\phi_i(v_i)\,f_i(v_i)\,dv_i, \text{ by the definition of } Q_i(v_i)\) \(\displaystyle =\) \(\displaystyle \int_{\underline{v}_i}^{\overline{v}_i}\mathbb{E}\!\left[q_i(v_i,V_{-i})\right]\,\phi_i(v_i)\,f_i(v_i)\,dv_i\) \(\displaystyle =\) \(\displaystyle \mathbb{E}\!\left[\mathbb{E}\!\left[q_i(V)\mid V_i\right]\,\phi_i(V_i)\right]\) \(\displaystyle =\) \(\displaystyle \mathbb{E}\!\left[q_i(V)\,\phi_i(V_i)\right], \text{ by the law of iterated expectations.}\)

Expected revenue is the sum of the expected payments from the buyers. Then, we can write expected revenue as

\(\displaystyle \sum_{i=1}^n \mathbb{E}\!\left[p_i(V)\right]\) \(\displaystyle =\) \(\displaystyle -\sum_{i=1}^n U_i(\underline{v}_i)+\mathbb{E}\!\left[\sum_{i=1}^n q_i(V)\,\phi_i(V_i)\right].\)

The Optimal Mechanism

Now, we will verify that our proposed optimal mechanism is indeed BIC, IR, and optimal. Recall that in a regular environment, \(\phi_i(v_i)\) is strictly increasing in \(v_i\) for each buyer \(i\). Then, for buyer \(i\), fix any realization of the other buyers' values \(v_{-i}\), given they report truthfully. For values \(v_{i,1},v_{i,2}\in T_i\) with \(v_{i,1}\lt v_{i,2}\),

\[ q_i^*(v_{i,1},v_{-i})\leq q_i^*(v_{i,2},v_{-i}). \]

Taking expectations gives \(Q_i^*(v_{i,1})\leq Q_i^*(v_{i,2})\). Then, interim allocation probabilities for all buyers are weakly increasing, satisfying one condition of Myerson's Lemma.

To verify that our payment rule satisfies the payment identity in Myerson's Lemma, fix any realization of the other buyers' values \(v_{-i}\) and suppose they report truthfully. Since \(\phi_i\) is strictly increasing, buyer \(i\) wins above \(x_i(v_{-i})\) and loses below it. Notice that for buyer \(i\),

\(\displaystyle \int_{\underline{v}_i}^{v_i}q_i^*(t,v_{-i})\,dt\) \(\displaystyle =\) \(\displaystyle \begin{cases}\int_{x_i(v_{-i})}^{v_i}1\,dt & \text{if }v_i\geq x_i(v_{-i}),\\0 & \text{otherwise}\end{cases}\) \(\displaystyle =\) \(\displaystyle \begin{cases}v_i-x_i(v_{-i}) & \text{if }q_i^*(v)=1,\\0 & \text{otherwise}\end{cases}\) \(\displaystyle =\) \(\displaystyle (v_i-x_i(v_{-i}))q_i^*(v).\)

Then, we can rewrite our payment rule for buyer \(i\) as

\[ p_i^*(v_i,v_{-i})=v_iq_i^*(v_i,v_{-i})-\int_{\underline{v}_i}^{v_i}q_i^*(t,v_{-i})\,dt. \]

Taking expectations gives

\(\displaystyle P_i^*(v_i)\) \(\displaystyle =\) \(\displaystyle \mathbb{E}_{V_{-i}}\!\left[p_i^*(v_i,V_{-i})\right]\) \(\displaystyle =\) \(\displaystyle \mathbb{E}_{V_{-i}}\!\left[v_iq_i^*(v_i,V_{-i})-\int_{\underline{v}_i}^{v_i}q_i^*(t,V_{-i})\,dt\right]\) \(\displaystyle =\) \(\displaystyle \mathbb{E}_{V_{-i}}\!\left[v_iq_i^*(v_i,V_{-i})\right]-\mathbb{E}_{V_{-i}}\!\left[\int_{\underline{v}_i}^{v_i}q_i^*(t,V_{-i})\,dt\right]\) \(\displaystyle =\) \(\displaystyle v_iQ_i^*(v_i)-\int_{\underline{v}_i}^{v_i}\mathbb{E}_{V_{-i}}\!\left[q_i^*(t,V_{-i})\right]\,dt,\text{ by Fubini's theorem}\) \(\displaystyle =\) \(\displaystyle v_iQ_i^*(v_i)-\int_{\underline{v}_i}^{v_i}Q_i^*(t)\,dt.\)

Then, this mechanism is BIC and IR. Notice that it sets \(U_i(\underline{v}_i)=0\) for each buyer \(i\) in the payment identity.
