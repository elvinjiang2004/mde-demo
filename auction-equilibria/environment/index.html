Environment

One object is to be sold. There are \(n\geq 2\) risk-neutral buyers. Buyers have independent private values \(V_i\sim F\), \(i=1,\ldots,n\). We assume that \(F\) has a continuous, strictly positive density \(f\) on its support \([\underline{v},\overline{v}]\). The distribution \(F\) is common knowledge.
