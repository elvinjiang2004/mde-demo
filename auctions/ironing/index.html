Ironing

A seller intends to sell an object for which she has no value. There are \(n\geq 2\) risk-neutral bidders. Bidders have independent private values \(V_i\sim F_i\), \(i=1,\ldots,n\). We assume that each \(F_i\) has a piecewise-continuous density \(f_i\), bounded above and away from zero, on its support \([\underline{v}_i,\overline{v}_i]\). These distributions are common knowledge.

The seller wishes to maximize expected revenue with a direct selling mechanism consisting of an allocation rule \(q:T\to[0,1]^n\) and a payment rule \(p:T\to\mathbb{R}^n\), where \(T=\prod_{i=1}^n[\underline{v}_i,\overline{v}_i]\). As functions of the reported values, for each bidder, the allocation rule specifies the probability the object is sold to him, and the payment rule specifies the expected payment from him. Writing \(q=(q_1,\ldots,q_n)\), since there is only one object to be sold, we require that for all \(v\in T\), \(\sum_{i=1}^n q_i(v)\leq 1.\)

We additionally require that the mechanism satisfies the following properties:

  1. (Bayesian) Incentive Compatibility (IC): All bidders truthfully reporting is a Bayesian Nash equilibrium.
  2. (Interim) Individual Rationality (IR): In truthful equilibrium, after observing their values, all bidders have a weakly positive expected payoff.

Theorem (): When the design problem is regular, meaning that each bidder's virtual value \(\phi_i(v_i)=v_i-\frac{1-F_i(v_i)}{f_i(v_i)}\) is weakly increasing, there is a revenue-maximizing auction that allocates the object to a bidder with the highest positive virtual value. Otherwise, if no bidder has a positive virtual value, the object is not sold.
