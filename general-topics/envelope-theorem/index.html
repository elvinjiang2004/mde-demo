The Envelope Theorem

A single agent wishes to maximize a real-valued function \(f(x,t)\) with \(t\in[0,1]\) with his choice of \(x\in X\). We call \(f\) the objective function, \(t\) a parameter, and \(x\) the choice variable. Denote the following:

  • \(V(t)=\sup\{f(x,t)\mid x\in X\}\), the value function or upper envelope of the family of functions \(\{f(x,t)\mid x\in X\}\).
  • \(X^*(t)=\operatorname*{arg\,max}\{f(x,t)\mid x\in X\}\), the set of maximizers at \(t\).
  • \(x^*(t)\in X^*(t)\ne\varnothing\), a particular selection from the non-empty set of maximizers at \(t\).

An envelope theorem is one which is concerned with the differentiability of \(V(t)\). There are many different envelope theorems (or perhaps many different versions of the same envelope theorem). The following are two that are unique in their generality.

Theorem 1 from Milgrom and Segal (2002) states,

Theorem: Let \(t\in(0,1)\) and suppose \(f_t(x^*(t),t)\) exists. If \(V\) is differentiable at \(t\), then

\[ V'(t)=f_t(x^*(t),t). \]

Theorem 2 from Milgrom and Segal (2002) states,

Theorem: Suppose the following conditions hold:

  1. \(f(x,t)\) is absolutely continuous in \(t\), for all \(x\in X\).
  2. There exists an integrable function \(b:[0,1]\to\mathbb{R}_{+}\) such that \(\lvert f_t(x,t)\rvert\le b(t)\) for all \(x\in X\) and almost all \(t\in[0,1]\).

Then, \(V\) is absolutely continuous and, thus, differentiable almost everywhere.

Suppose additionally,

  1. \(f(x,t)\) is differentiable at every \(t\in[0,1]\), for all \(x\in X\).
  2. \(X^*(t)\ne\varnothing\) at almost every \(t\in[0,1]\).

Then, for all \(t\in[0,1]\)

\[ V(t)=V(0)+\int_0^t f_t(x^*(s),s)\,ds. \]

The Envelope Theorem for mechanisms

We will use a simple problem that carries many important features in its analysis to exemplify the envelope theorem's application in mechanism design. There is one monopoly seller and one buyer. The seller has value \(0\) for the object, while the buyer has value \(V\sim F\), where \(F\) has support \([0,1]\). The seller does not know the buyer's value, so chooses a direct mechanism ahead of time with allocation rule \(q(v')\) and payment rule \(p(v')\). Given the buyer reports \(v'\), the allocation rule specifies the probability of allocation and the payment rule specifies the amount the buyer must pay. Then, the buyer's utility function is \(u(v,v')=vq(v')-p(v')\), where \(v\) is his value and \(v'\) is his reported value.

Now let's connect some of the abstract terms in Milgrom and Segal (2002) to this specific problem. From the buyer's perspective,

  • Objective function: \(u(v,v')=vq(v')-p(v')\), the buyer's utility.
  • Choice variable: \(v'\in[0,1]\), the buyer's reported value.
  • Parameter: \(v\in[0,1]\), the buyer's randomly drawn value.

We assume \(p(v')\) is finite for all \(v'\in[0,1]\), so that \(u(v,v')\) is finite for all \(v,v'\in[0,1]\).

In equilibrium, the buyer maximizes his utility by choosing the best report \(v'\) given his value \(v\). Then,

  • Value function: \(U(v)=\sup\{u(v,v')\mid v'\in[0,1]\}\), the buyer's equilibrium utility.
  • Family of functions: \(\{u(\cdot,v')\mid v'\in[0,1]\}\), the buyer's utility functions indexed by reports.
  • Set of maximizers: \(V^*(v)=\operatorname*{arg\,max}\{u(v,v')\mid v'\in[0,1]\}\), the set of optimal reports at \(v\).
  • Selection from the set of maximizers: \(v^*(v)\in V^*(v)\), an optimal report selected from the non-empty set of maximizers at \(v\).

In many cases, and certainly in this case, we will restrict our attention to incentive-compatible mechanisms. These mechanisms, by definition, are such that reporting truthfully (that is, reporting \(v\) when your value is \(v\)) maximizes utility. Then, in an incentive-compatible mechanism, for every \(v\in[0,1]\), \(v\in V^*(v)\). Theorem 1 says that, if \(U\) is differentiable at \(v\in (0,1)\), \(U'(v)=u_v(v,v^*(v))=q(v^*(v))\). In an incentive-compatible mechanism, we can select \(v^*(v)=v\), so \(U'(v)=q(v)\).

Now, look at the conditions of Theorem 2. Are they satisfied? Clearly, condition 1 is satisfied: with \(v'\) fixed, \(u\) is affine in \(v\). For condition 2, as we stated earlier, \(u_v(v,v')=q(v')\), and \(q(v')\in[0,1]\) by definition. So, we can choose our bounding function \(b\) as \(b(v)=1\), which is clearly integrable. Theorem 2 now states that \(U\) is absolutely continuous and, thus, differentiable almost everywhere.

Condition 3 is also clearly satisfied because \(u\) is affine in \(v\) with \(v'\) fixed. Condition 4 is satisfied automatically by incentive compatibility, since \(v\in V^*(v)\) for all \(v\in[0,1]\). Theorem 2 then says that, for an incentive-compatible mechanism,

\[ U(v)=U(0)+\int_0^v q(t)\,dt. \]

A consequence of this is that, given an allocation rule \(q\), incentive compatibility pins down the shape of $U$ and, thus, the payment rule \(p\), leaving freedom only in the choice of \(U(0)\).
