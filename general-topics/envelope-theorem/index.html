The Envelope Theorem

A single agent wishes to maximize a real-valued function \(f(x,t)\) by choosing \(x\in X\), for a given parameter \(t\in T=[0,1]\)1. We call \(f:X\times T\to\mathbb{R}\) the objective function, \(t\) a parameter, and \(x\) the choice variable. Define the following:

  • Value function: \(V(t)=\sup\{f(x,t)\mid x\in X\}\), the upper envelope of the family of functions \(\{f(x,t)\mid x\in X\}\).
  • Set of maximizers: \(X^*(t)=\operatorname*{arg\,max}\{f(x,t)\mid x\in X\}\).
  • Selection: \(x^*(t)\in X^*(t)\), a particular maximizer when \(X^*(t)\) is nonempty.

Envelope theorems characterize how \(V(t)\) behaves as the parameter \(t\) varies. give the following two results for arbitrary choice sets.

Theorem 1 (): Let \(t\in(0,1)\) and suppose \(f_t(x^*(t),t)\) exists. If \(V\) is differentiable at \(t\), then

\[ V'(t)=f_t(x^*(t),t). \]

Theorem 2 (): Suppose the following conditions hold:

  1. \(f(x,t)\) is absolutely continuous in \(t\), for all \(x\in X\).
  2. There exists an integrable function \(b:T\to\mathbb{R}_{+}\) such that \(\lvert f_t(x,t)\rvert\le b(t)\) for all \(x\in X\) and almost all \(t\in T\).

Then \(V\) is absolutely continuous and, therefore, differentiable almost everywhere.

Suppose additionally that:

  1. \(f(x,t)\) is differentiable at every \(t\in T\), for all \(x\in X\).
  2. \(X^*(t)\ne\varnothing\) at almost every \(t\in T\).

Then, for every \(t\in T\)

\[ V(t)=V(0)+\int_0^t f_t(x^*(s),s)\,ds. \]

Myerson's Lemma

We will use the Envelope Theorem (specifically, Theorem 2) to prove an important result in mechanism design. Consider the single-item auction environment. Myerson (1981) gives the following result about what allocation rules are implementable.

Theorem (Myerson's Lemma): An allocation rule \(q\) is BIC (respectively, DSIC) implementable if and only if for \(i=1,\ldots,n\),

  1. \(Q_i(v_i)\) is weakly increasing (respectively, \(q_i(v_i,v_{-i})\) is weakly increasing in \(v_i\) for every fixed \(v_{-i}\)).
  2. \(\displaystyle P_i(v_i)\) \(\displaystyle =\) \(\displaystyle v_iQ_i(v_i)-\int_{\underline{v}_i}^{v_i}Q_i(t)\,dt-U_i(\underline{v}_i)\) (respectively, \(\displaystyle p_i(v_i,v_{-i})\) \(\displaystyle =\) \(\displaystyle v_iq_i(v_i,v_{-i})-\int_{\underline{v}_i}^{v_i}q_i(t,v_{-i})\,dt-u_i(\underline{v}_i,v_{-i})\)).

Proof (BIC version): Start with the forward direction. Fix a buyer \(i\in\{1,\ldots,n\}\). Suppose \(q\) is BIC implementable with payment rule \(p\), so \((q,p)\) is BIC. For all \(v_i^1,v_i^2\in[\underline{v}_i,\overline{v}_i]\) with \(v_i^1\lt v_i^2\), BIC gives

\(\displaystyle U_i(v_i^1)\geq U_i(v_i^1,v_i^2)\) \(\displaystyle \text{and}\) \(\displaystyle U_i(v_i^2)\geq U_i(v_i^2,v_i^1)\) \(\displaystyle \iff v_i^1Q_i(v_i^1)-P_i(v_i^1)\geq v_i^1Q_i(v_i^2)-P_i(v_i^2)\) \(\displaystyle \text{and}\) \(\displaystyle v_i^2Q_i(v_i^2)-P_i(v_i^2)\geq v_i^2Q_i(v_i^1)-P_i(v_i^1)\) \(\displaystyle \iff v_i^1Q_i(v_i^1)-v_i^1Q_i(v_i^2)\geq P_i(v_i^1)-P_i(v_i^2)\) \(\displaystyle \text{and}\) \(\displaystyle v_i^2Q_i(v_i^2)-v_i^2Q_i(v_i^1)\geq P_i(v_i^2)-P_i(v_i^1)\) \(\displaystyle \iff v_i^1(Q_i(v_i^1)-Q_i(v_i^2))\geq P_i(v_i^1)-P_i(v_i^2)\) \(\displaystyle \text{and}\) \(\displaystyle v_i^2(Q_i(v_i^2)-Q_i(v_i^1))\geq P_i(v_i^2)-P_i(v_i^1).\) \(\displaystyle \iff -v_i^1(Q_i(v_i^2)-Q_i(v_i^1))\geq P_i(v_i^1)-P_i(v_i^2)\) \(\displaystyle \text{and}\) \(\displaystyle v_i^2(Q_i(v_i^2)-Q_i(v_i^1))\geq P_i(v_i^2)-P_i(v_i^1)\) \(\displaystyle \implies (v_i^2-v_i^1)(Q_i(v_i^2)-Q_i(v_i^1))\) \(\displaystyle \geq\) \(\displaystyle 0.\)

Then, since \(v_i^2>v_i^1\), we have \(Q_i(v_i^2)-Q_i(v_i^1)\geq 0\), so \(Q_i\) is weakly increasing. Additionally, for all \(v_i\in[\underline{v}_i,\overline{v}_i]\), BIC gives

\(\displaystyle U_i(v_i)\) \(\displaystyle =\) \(\displaystyle \sup\left\{v_iQ_i(v_i')-P_i(v_i')\mid v_i'\in[\underline{v}_i,\overline{v}_i]\right\}.\)

Then, interim truthful utility is the upper envelope of a family of affine functions in \(v_i\). For each fixed report \(v_i'\), the slope is \(Q_i(v_i')\in[0,1]\), and BIC ensures the maximum is attained at the truthful report. Theorem 2 gives the following integral condition.

\(\displaystyle U_i(v_i)\) \(\displaystyle =\) \(\displaystyle U_i(\underline{v}_i)+\int_{\underline{v}_i}^{v_i}Q_i(t)\,dt.\)

Then solving for the interim expected payment,

\(\displaystyle U_i(\underline{v}_i)+\int_{\underline{v}_i}^{v_i}Q_i(t)\,dt\) \(\displaystyle =\) \(\displaystyle v_iQ_i(v_i)-P_i(v_i)\) \(\displaystyle \iff\) \(\displaystyle P_i(v_i)\) \(\displaystyle =\) \(\displaystyle v_iQ_i(v_i)-U_i(\underline{v}_i)-\int_{\underline{v}_i}^{v_i}Q_i(t)\,dt.\)

For the reverse direction, suppose \(Q_i\) is weakly increasing for every buyer \(i\). Define \(P_i\) as above, and set the payment rule as \(p_i(v_i,v_{-i})=P_i(v_i)\). Let's verify that this mechanism is BIC. For a buyer with value \(v_i\), for all \(v_i'\in[\underline{v}_i,\overline{v}_i]\), the difference between the expected payoff from truthfully reporting \(v_i\) and misreporting \(v_i'\) is

\(\displaystyle U_i(v_i) - U_i(v_i,v_i') \) \(\displaystyle = \) \(\displaystyle \left[v_i Q_i(v_i)-P_i(v_i)\right] - \left[v_i Q_i(v_i')-P_i(v_i')\right] \) \(\displaystyle \) \(\displaystyle \) \(\displaystyle = \) \(\displaystyle \left[v_i Q_i(v_i)-\left(v_i Q_i(v_i)-U_i(\underline{v}_i)-\int_{\underline{v}_i}^{v_i} Q_i(t)\, dt\right)\right] - \left[v_i Q_i(v_i')-\left(v_i'Q_i(v_i')-U_i(\underline{v}_i)-\int_{\underline{v}_i}^{v_i'} Q_i(t)\, dt\right)\right] \) \(\displaystyle \) \(\displaystyle \) \(\displaystyle = \) \(\displaystyle U_i(\underline{v}_i) - U_i(\underline{v}_i) + \int_{\underline{v}_i}^{v_i} Q_i(t)\, dt - v_i Q_i(v_i')+v_i'Q_i(v_i')-\int_{\underline{v}_i}^{v_i'} Q_i(t)\, dt \) \(\displaystyle \) \(\displaystyle \) \(\displaystyle = \) \(\displaystyle Q_i(v_i')(v_i'-v_i) + \int_{v_i'}^{v_i} Q_i(t)\, dt \) \(\displaystyle =\) \(\displaystyle \int_{v_i'}^{v_i}\left[Q_i(t)-Q_i(v_i')\right]\,dt.\)

Because \(Q_i\) is weakly increasing, this difference is weakly positive for all \(v_i,v_i'\in[\underline{v}_i,\overline{v}_i]\). If \(v_i'\leq v_i\), the integrand is weakly positive, and the limits are in increasing order; if \(v_i'>v_i\), the integrand is weakly negative, and the limits are in decreasing order. The argument applies to every buyer, so the mechanism is BIC. \(\blacksquare\)

Notes
