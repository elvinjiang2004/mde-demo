The Revelation Principle

There are \(n\) agents and a set of possible outcomes \(Y\), specified by a principal or designer. For each agent \(i\), \(i=1,\ldots,n\), define the following:

  • Type: \(\theta_i\in T_i\). We call \(T=\prod_{i=1}^n T_i\) the type space and write \(\theta=(\theta_1,\ldots,\theta_n)\in T\) and \(\theta_{-i}=(\theta_1,\ldots,\theta_{i-1},\theta_{i+1},\ldots,\theta_n)\).
  • Belief: The distribution of the other agents' types, conditional on the agent's own type, \(p_i(\theta_{-i}\mid\theta_i)\).
  • Expected utility: The expected utility conditional on the outcome and all agents' types, \(U_i(y,\theta)\), where \(y\in Y\).

A mechanism maps actions to outcomes. Then, we write it as an ordered pair \((A,f)\), consisting of an action space \(A=\prod_{i=1}^n A_i\) and an outcome function \(f:A\to Y\). It induces a game in which each agent \(i\) learns their type \(\theta_i\), chooses an action in \(A_i\), and receives payoffs based on \(U_i\).

We use two solution concepts: Bayesian Nash Equilibrium (BNE) and Dominant Strategy Equilibrium (DSE). Selecting an equilibrium in the induced game, when one exists, gives a mapping from type profiles to outcomes, which we call an outcome rule, \(g:T\to Y\). We say that this mechanism implements this outcome rule in BNE (respectively, DSE).

The designer may have an objective, for example, to maximize expected revenue among all feasible mechanisms. However, the space of mechanisms the designer must search for an optimal one is vast because there is no limit on how large the action space \(A\) can be. The revelation principle reduces this space considerably. It shows that, without loss of generality, we can consider direct revelation mechanisms, whose action space \(A\) is equal to the type space \(T\). An action in such a mechanism is interpreted as a report of a type.

Theorem (The Revelation Principle): An outcome rule is implemented by a mechanism in BNE (respectively, DSE) if and only if it is implemented by a direct revelation mechanism where truthful reporting is a BNE (respectively, DSE).

Proof of the Revelation Principle

You may notice in the demo you cannot increase your payoff in the direct mechanism by misrepresenting your preferences. That is, for all preference profiles, it is optimal for you to report truthfully in the direct mechanism. The simulated rounds give an idea as to why and show the Revelation Principle proof's general idea: a direct mechanism can just execute the equilibrium strategies of any indirect one. Let's verify this more rigorously.

The reverse direction of the Revelation Principle is obvious for both versions. For the forward direction of the BNE version, suppose that a mechanism \((A,f^I)\) induces a game with a BNE \(s^*=(s_1^*,\ldots,s_n^*)\) where \(s_i^*:T_i\to A_i\). Consider the mechanism \((T,f^D)\) with \(f^D(\theta)=f^I\bigl(s_1^*(\theta_1),\ldots,s_n^*(\theta_n)\bigr)\).

For agent \(i\), in the game induced by \((A,f^I)\), since \((s_1^*,\ldots,s_n^*)\) is a BNE, for all realizations of \(\theta_i\in T_i\), \(s_i^*(\theta_i)\) is an optimal action given the others use the strategy profile \(s_{-i}^*=(s_1^*,\ldots,s_{i-1}^*,s_{i+1}^*,\ldots,s_n^*)\). That is, for all \(\theta_i\in T_i\), for all \(a_i\in A_i\),

\(\displaystyle \mathbb{E}_{\theta_{-i}}\!\left[ U_i\!\left(f^I\bigl(s_i^*(\theta_i),s_{-i}^*(\theta_{-i})\bigr), (\theta_i,\theta_{-i})\right)\mid\theta_i\right]\) \(\displaystyle \geq\) \(\displaystyle \mathbb{E}_{\theta_{-i}}\!\left[ U_i\!\left(f^I\bigl(a_i,s_{-i}^*(\theta_{-i})\bigr), (\theta_i,\theta_{-i})\right)\mid\theta_i\right].\)

In particular, for all \(\theta_i\in T_i\), for all \(\hat{\theta}_i\in T_i\),

\(\displaystyle \mathbb{E}_{\theta_{-i}}\!\left[ U_i\!\left(f^I\bigl(s_i^*(\theta_i),s_{-i}^*(\theta_{-i})\bigr), (\theta_i,\theta_{-i})\right)\mid\theta_i\right]\) \(\displaystyle \geq\) \(\displaystyle \mathbb{E}_{\theta_{-i}}\!\left[ U_i\!\left(f^I\bigl(s_i^*(\hat{\theta}_i),s_{-i}^*(\theta_{-i})\bigr), (\theta_i,\theta_{-i})\right)\mid\theta_i\right]\) \(\displaystyle \iff\) \(\displaystyle \mathbb{E}_{\theta_{-i}}\!\left[ U_i\!\left(f^D\bigl((\theta_i,\theta_{-i})\bigr), (\theta_i,\theta_{-i})\right)\mid\theta_i\right]\) \(\displaystyle \geq\) \(\displaystyle \mathbb{E}_{\theta_{-i}}\!\left[ U_i\!\left(f^D\bigl((\hat{\theta}_i,\theta_{-i})\bigr), (\theta_i,\theta_{-i})\right)\mid\theta_i\right].\)

Thus, truthful reporting is a BNE in the game induced by \((T,f^D)\). Clearly, in this BNE, the mechanism implements the same outcome rule.

For the forward direction of the DSE version, suppose instead that \(s^*=(s_1^*,\ldots,s_n^*)\) is a DSE. Then, for agent \(i\), for all realizations of \(\theta\in T\), \(s_i^*(\theta_i)\) is an optimal action for any actions the others use \(a_{-i}=(a_1,\ldots,a_{i-1},a_{i+1},\ldots,a_n)\). That is, for all \(\theta\in T\), for all \(a=(a_i,a_{-i})\in A\),

\(\displaystyle U_i\!\left(f^I\bigl(s_i^*(\theta_i),a_{-i}\bigr), \theta\right)\) \(\displaystyle \geq\) \(\displaystyle U_i\!\left(f^I(a_i,a_{-i}), \theta\right).\)

In particular, for all \(\theta\in T\), for all \(\hat{\theta}=(\hat{\theta}_i,\hat{\theta}_{-i})\in T\),

\(\displaystyle U_i\!\left(f^I\bigl(s^*(\theta_i,\hat{\theta}_{-i})\bigr), \theta\right)\) \(\displaystyle \geq\) \(\displaystyle U_i\!\left(f^I\bigl(s^*(\hat{\theta}_i,\hat{\theta}_{-i})\bigr), \theta\right)\) \(\displaystyle \iff\) \(\displaystyle U_i\!\left(f^D(\theta_i,\hat{\theta}_{-i}), \theta\right)\) \(\displaystyle \geq\) \(\displaystyle U_i\!\left(f^D(\hat{\theta}_i,\hat{\theta}_{-i}), \theta\right).\)

Thus, truthful reporting is a DSE in the game induced by \((T,f^D)\).

Notes

  • The direct revelation implementation of a mechanism is not necessarily strategically equivalent to the original mechanism.
