The Revelation Principle

There are \(N\) agents and a set of possible outcomes \(Y\ni y\) specified by a principal or designer. Succinctly, a mechanism maps actions to outcomes. We can encode a mechanism as an ordered pair \((A,f)\), consisting of the action space \(A=A_1\times\cdots\times A_N\) and a function \(f:A\to Y\). Next, define the following for each agent \(i\), \(i=1,\ldots,N\):

  • His/her type: \(\theta_i\in\Theta_i\).
  • His/her belief about the distribution of other agents' types, conditional on his/her own type: \(p_i(\theta_{-i}\mid\theta_i)\).
  • His/her utility function, conditional on the outcome and all agents' types: \(U_i(y,\theta)\).

Where \(\theta=(\theta_1,\ldots,\theta_N)\) and \(\theta_{-i}=(\theta_1,\ldots,\theta_{i-1},\theta_{i+1},\ldots,\theta_N)\).

A mechanism with these agent characteristics induces a game where each agent \(i\) learns his/her type \(\theta_i\), chooses an action in \(A_i\), and receives payoffs based on \(U_i\). We predict behavior in this game primarily using two solution concepts: Bayesian-Nash equilibrium (BNE) and dominant-strategy equilibrium (DSE). We assume the designer may only use mechanisms that induce at least one of these equilibria. Then, we can see a mechanism as inducing a game which induces some equilibria each of which, for each type, induces an outcome. Selecting one of these equilibria, we can summarize this chain as a mechanism inducing a mapping from types to outcomes, which we call an outcome rule.

The designer may have an external goal, such as revenue maximization. However, the space the designer must search to find, for example, a revenue-maximizing mechanism is vast. There is no limit on how large the action space \(A\) can be. The revelation principle helps greatly in narrowing this search. It tells us that, without loss of generality, we can consider only direct revelation mechanisms whose action space equals the type space. We interpret an action in such a mechanism as reporting a type.

Theorem (The Revelation Principle). An outcome rule is induced by a mechanism in BNE(respectively, DSE) if and only if it is induced by a direct revelation mechanism where agents report truthfully in BNE(respectively, DSE).
