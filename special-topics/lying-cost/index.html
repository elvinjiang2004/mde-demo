Bilateral Trade with Lying Costs

In my paper Bilateral Trade with Lying Costs, I consider the (bilateral trade environment), but agents incur a disutility from misreporting their values. For the buyer, given his true value \(v\), reporting to have value \(v'\) gives a commonly known disutility of \(\gamma_B|v-v'|\) and likewise for a seller with true value \(c\), report \(c'\), and coefficient \(\gamma_S\).

I show the following results:

Proposition 1: If and only if \(\gamma_B=\gamma_S=0\), for all value distributions, the efficient allocation rule is not implementable.

Proposition 2: If and only if \(\gamma_B+\gamma_S\geq 1\), for all value distributions, the efficient allocation rule is implementable.

Proposition 3: If and only if \(\sqrt{\gamma_B}+\sqrt{\gamma_S}\geq 1\), when the buyer and seller have the same value distribution, the efficient allocation rule is implementable.

In the interactive demo, consider a specific example with the buyer value \(V\sim\mathrm{Uniform}[0,1]\) and the seller value \(C\sim\mathrm{Uniform}[1-\epsilon,2-\epsilon]\) with \(0\leq\epsilon\leq 1\). Adjust the buyer's and seller's lying costs and the value supports' overlap to see when the efficient allocation rule is implementable. For the k-Double-Auction, adjust \(k\), the weight on the buyer's report in the price \(kv+(1-k)c\), and notice when the mechanism becomes incentive compatible.
