Environment

There are \(n\geq 2\) voters who must elect one candidate from a finite, nonempty set of candidates \(E\). Voters have private preferences over \(E\), denoted \(\preceq_i\), \(i=1,\ldots,n\). We assume each \(\preceq_i\) is complete, transitive, reflexive, and antisymmetric as a relation over \(E\). That is, it is a linear order over \(E\). We interpret \(a\preceq_i b\) as voter \(i\) weakly prefers \(b\) to \(a\). Additionally, for each \(i=1,\ldots,n\), for any two candidates \(a,b\in E\), if \(a\preceq_i b\) and \(b\preceq_i a\), we can write \(a\sim_i b\); if \(a\preceq_i b\) but not \(b\preceq_i a\), we can write \(a\prec_i b\). Since \(\preceq_i\) is a linear order, \(a\sim_i b\) if and only if \(a=b\), and \(a\prec_i b\) if and only if \(a\preceq_i b\) and \(a\ne b\).

By the Revelation Principle, to implement any outcome rule (sometimes called a social choice function in this setting) that is implementable in dominant strategies, we can restrict attention to direct voting mechanisms which consist of a function \(f:T\to E\), where \(T=\prod_{i=1}^n T_i\) and \(T_i\) is the set of admissible linear orders over \(E\) for voter \(i\).

Note that dominant strategies here are defined with preference relations, rather than with utilities. Since there are a finite number of candidates, and the preference relations are linear orders over \(E\), it is equivalent to set utilities as \(u_i(A)=-\text{rank}_i(A)\), where \(\text{rank}_i(A)\) is the rank of candidate \(A\) in voter \(i\)'s preference ordering and use the definition with utilities.

Define the following properties of a direct voting mechanism:

  1. Dominant-Strategy Incentive Compatibility (DSIC or Strategy-Proofness): For each voter \(i\), truthful reporting is a dominant strategy.
  2. Dictatorial: There is a voter who always gets her most preferred candidate. Such a voter is called a dictator.
  3. Surjective (Onto): The mechanism's function is surjective.
